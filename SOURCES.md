# Source record

Every source used to build or tune data that ships in the package is recorded
here before it is used. Raw downloads are never committed; this record plus the
data builder is enough to rebuild the data exactly.

Allowed licenses: MIT, BSD, Apache-2.0, ISC, public domain / CC0, CC BY, and
permissive word-list licenses such as SCOWL's. Not allowed: non-commercial
terms, GPL, AGPL, and for now share-alike (CC BY-SA), LGPL and MPL.
